# MODO INTERIORS — Static Company Profile

3 halaman:
- index.html — Home
- about.html — Tentang Kami
- katalog.html — Katalog

Tidak memakai framework agar mudah dikembangkan. JavaScript dipakai untuk interaksi katalog.

## Menambahkan foto hero
Simpan foto ruangan Anda dengan nama:
assets/hero-room.jpg

## Menambahkan variasi katalog
Tambahkan gambar ke folder assets lalu edit data/detail pada:
js/catalog.js

Contoh SPC sudah memakai:
- assets/spc-room-reference.png
- assets/spc-variants.png
